# Laiba Imran — Portfolio

A bold, cute editorial-style developer portfolio built with plain HTML, CSS and JavaScript.

## Run locally

Open `index.html` directly in your browser, or use VS Code Live Server.

## Deploy on GitHub Pages

1. Create a new GitHub repository.
2. Upload **all files and folders inside this project**.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`.
6. Save and wait for GitHub Pages to publish.
